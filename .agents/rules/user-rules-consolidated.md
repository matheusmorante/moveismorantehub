# Regras do Usuário Consolidadas - Morante Hub

- Siga princípio de código limpo e modularizado.
- Sempre salve ideias e planos pendentes em um arquivo para posterior consulta e lembrete.
- Economize o máximo de cota que puder do plano de assinatura.
- Considere sempre o ambiente de desenvolvimento e produção ao configurar rotas, variáveis de ambiente e outros dados ambíguos para funcionar corretamente em ambos os ambientes.
- Relate imediatamente bugs que estejam impedindo o progresso para ciência do usuário.
- Pergunte se tiver dúvida de ambiguidade ou entendimento no que o usuário disser ou mostrar.
- Salve os rules sempre em um arquivo do projeto.
- Fale apenas em português brasileiro.

# Skill de Modularização e Código Limpo

## Instruções

1. **Limite de 200 Linhas por Arquivo**:
   - Sempre que criar um novo arquivo ou editar um arquivo existente no projeto Morante Hub, certifique-se de que o arquivo não exceda **200 linhas**.
   - Se um arquivo ultrapassar 200 linhas, divida-o em sub-componentes, helpers, utilitários ou módulos em diretórios dedicados (ex: `components/`, `utils/`, `services/`, `hooks/`).

2. **Verificação pós-tarefa**:
   - Ao concluir a implementação de qualquer funcionalidade ou correção, analise se os arquivos modificados ou criados permanecem abaixo de 200 linhas e aplique a refatoração necessária para código limpo.
